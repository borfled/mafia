# Mafia

A social deduction game built and refined by David Le with ChatGPT Work.

**[Play the game](https://mafia.davidle826.chatgpt.site/)**

## Overview

Players take secret roles and work out who is Mafia through discussion and voting. The project supports rooms shared by code and solo practice with personality-driven bots. Its Handshake showcase describes live chat, an automatic narrator, Mafia/Sheriff/Medic turns, and mobile support.

## Repository status

This is currently a project showcase and link to the hosted game. The application source code has not been imported into this repository, so there are no local setup instructions yet.
